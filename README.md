
# Sistema Web de Gestión de PQRS

Plataforma web para la gestión, seguimiento y trazabilidad
de peticiones, quejas, reclamos y sugerencias.

## Tecnologías
- Node.js
- Express
- SQLite
- JavaScript
- HTML y CSS
- Nodemailer
- Puppeteer
- ExcelJS
- Docker

## Funcionalidades
- Registro de PQRS.
- Generación de códigos consecutivos.
- Seguimiento de solicitudes.
- Registro de respuestas.
- Adjuntar documentos.
- Generación de PDF.
- Exportación de reportes Excel.
- Panel administrativo.

## Instalación local

1. Instalar Node.js 20 o superior.
2. Clonar el repositorio.
3. Ejecutar npm install.
4. Configurar el archivo .env.
5. Ejecutar npm start.

## Ejecución

http://localhost:3000

## Despliegue

Aplicación preparada para despliegue mediante Docker.
